RULES

1. The syllabus decides the topics. Make one topic for each topic in the syllabus, in syllabus order. Merge tiny sub-points into their topic. Aim for 6 to 40 topics.
   Leave out anything in the materials that is not in the syllabus. The only exception is background that a syllabus topic depends on (for example a formula needed to explain it): that may appear inside that topic's lesson, never as a topic of its own.

2. Use the materials first. Where the materials cover a topic, take facts, wording and examples from them, and set "source": "materials" on those facts and worked examples.

3. Fill the gaps. Where the materials do not cover a topic, or part of one, write it yourself from standard textbook knowledge for {{CATEGORY}} (search the web if you can), at the standard of the real exam, and set "source": "ai". Never leave a syllabus topic without lessons.

4. Be correct. Double-check every fact, every answer and every step of arithmetic. If you are unsure of something, leave it out rather than guess.

5. Every topic has exactly 3 levels, each clearly harder than the one before, never repeating earlier facts:
   - Level 1, easy: core definitions and basic ideas.
   - Level 2, medium: applying ideas and connecting concepts.
   - Level 3, hard: exam-standard questions and tricky distinctions.

6. Each level has exactly 3 facts. Each fact has:
   - "t": the fact in 1 to 2 sentences.
   - "why": an explanation of why it is true or how it works, in 2 to 4 sentences, for a secondary-school student.
   - "ex": a practical example, everyday scenario or exam-style illustration, or "" if none would help.
   - "q": exactly 2 questions, answerable from the fact and its explanation.
   - "source": "materials" or "ai" (see rules 2 and 3).
   - "img": a picture id (see rule 11) or null.

7. Questions. Each question has "k", "d" ("easy", "medium" or "hard"), "p" (the question) and "sol" (1 to 3 sentences on why the right answer is right). Kinds:
   - "mc": multiple choice with exactly 4 options in "o", and "a" = the 0-based index of the correct option (0 = first option). Vary which position is correct.
   - "tf": true or false, with "a" = true or false.
   - "in" (level 3 only): a short typed answer of 1 to 3 words, with "a" = a list of accepted lowercase answers. No LaTeX in typed answers.

8. Calculation topics. If a topic involves calculations or numerical problem solving, set "calc": true and give every level 1 or 2 worked examples in "worked" (1 if the method is simple, 2 if it is harder). Each worked example has:
   - "p": the problem with all data given.
   - "steps": short steps showing the formula, every substitution and the arithmetic.
   - "ans": the final answer with units.
   - "why": why the answer is correct (a sense check or unit check).
   - "mistakes": 2 to 3 common mistakes students make on this kind of problem.
   - "q": 1 to 3 practice questions like it, all "mc", each with "d", "p", "o", "a", "steps" (its worked solution) and "sol".
   - "source" and "img" as for facts.
   For other topics set "calc": false and "worked": [].

9. "sessions": how many 15-minute study sessions a typical student needs to learn and practise the topic to exam standard, from 1 to 12. More for long, technical or calculation-heavy topics.

10. Past questions (only if I gave you past question papers). Copy every multiple-choice question exactly as written, without rewording. Put the options in "o" without their letter labels.
   - "a": the 0-based index of the correct option. Take it from the paper's answer key and set "answer_source": "paper". If no answer key covers the question, work it out carefully and set "answer_source": "ai".
   - "sol": copy the paper's explanation if it has one and set "explanation_source": "paper"; otherwise write 2 to 4 sentences on why the answer is right and set "explanation_source": "ai". For calculations also give "steps".
   - "topic": the exact name of the matching topic from your topic list.
   - "year": the exam year if the paper shows it, otherwise "".
   - "d": "easy", "medium" or "hard".
   - Skip instructions, adverts, page numbers and anything that is not a question.
   Theory questions (essay, "describe", "explain", "show that", calculations to be written out): copy each part (a), (b)(i) and so on as its own question, exactly as written, with "k": "th" and:
   - "ctx": the shared text the part depends on (the question's introduction or scenario), copied exactly; "" if none.
   - "p": the part itself, exactly as written. "marks": its marks from the paper (or your estimate if none are shown).
   - "points": the key points a full-marks answer must contain, one per mark or per idea, each { "t": the point in one sentence, "kw": 2 to 6 short phrases or values, any one of which shows the point was made, "m": marks for that point }. Students' answers are checked by looking for these phrases, so give the common ways of saying the point (for example ["absolutely integrable", "absolutely summable", "integral of |x(t)| is finite"]). Join words with " + " when all of them must appear (for example "finite + discontinuities"). Use plain words and numbers in "kw", never LaTeX.
   - "final": the correct final answer(s) a student would end with, as a list of 1 to 6 short phrases or values, any one of which counts (for example ["2.5 A", "2.5 amps", "2.5 amperes"]). Join words with " + " when all of them must appear (for example "x = 2 + x = -3" for two answers). Students earn XP for the final answer alone, and more for the key points in their workings. Use plain words and numbers, never LaTeX. For a "describe" or "explain" question, give the main conclusion in a few words.
   - "model": a model answer worth full marks, as a student should write it.
   - "topic", "year", "d" and "img" as above. No "o", "a", "sol" or source fields.

11. Pictures. Use "img" only where a picture genuinely helps. Its value must be either the id from a [FIGURE id: caption] marker in the materials (for example "i1abc2de"), or the file name of an image I attached. Otherwise use null. Never invent ids. A question that uses a picture must refer to it ("Study the diagram above.") and be answerable by looking at it. Several past questions may share one picture.

12. Maths and chemistry formatting. Write every formula, power, fraction or equation in LaTeX inside \( and \), for example \(\dfrac{22}{44} = 0.5\ \text{mol}\) (use \dfrac for fractions), \(x^{2}\), \(6.02 \times 10^{23}\). Write chemical formulas and equations with \ce{} inside \( \), for example \(\ce{H2O}\), \(\ce{2H2 + O2 -> 2H2O}\), \(\ce{Na+}\). Because the reply is JSON, every backslash must be doubled inside JSON strings: write "\\(\\dfrac{1}{2}\\)" and "\\(\\ce{H2O}\\)". Plain words stay plain text.

13. Extra notes (optional). Each level may have "extra_notes": a Markdown string of 150–600 words that goes deeper than the facts: derivations, why methods work, background maths the level depends on, and connections between ideas. Use ## / ### headings, short paragraphs, lists and tables. Write maths in LaTeX with \( \) inline and \[ \] for displayed formulas (double the backslashes in JSON). Do not repeat the facts word for word.
